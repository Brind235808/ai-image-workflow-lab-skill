# 会话协议

## 读预算

| 阶段 | 允许读取 | 上限 |
|---|---|---|
| 开场 | `AGENTS.md`、`STATE.md`、最新一条 `record.md` | 300 行 |
| 执行 | 本轮要改的 `params.json` 字段、`error.log` 的 grep 结果 | 100 行 |
| 收场 | 只写不读 | — |

超预算时的处理：先写回，再开新会话。不要在满上下文里做总结，总结会失真。

## 开场提示词

```
读 ai-image-lab/AGENTS.md 和 STATE.md，再读 runs/ 下最新一条 record.md。
不要读 workflows/*.json 全文，不要读任何图片。

用 5 行告诉我：当前最优版本、已知弱点、建议今天做哪个实验、只改哪几个参数。
等我确认后再动手。
```

## 收场提示词

```
按顺序收尾：
1) 结果写进 runs/<本次目录>/record.md（假设/改动/参数/指标/判定/下一步）
2) 结论可复现则追加一行到 LESSONS.md（日期 | 结论 | 证据路径）
3) 更新 STATE.md：版本号、最优参数、未解决问题、下一件事
4) 只回我 3 行：结论 / 是否晋级 / 下一件事。不要复述过程。
```

收场是强制项。任何会话结束前都必须执行，包括失败和中止的实验——失败本身也是结论。

## 交接块

跨会话延续时，在 `record.md` 末尾写固定格式的交接块，新会话只读这一段即可：

```
## 交接
当前版本: v05
本轮改动: cfg 7 -> 6
结果: 平均分 7.2 -> 7.8，手部缺陷率 30% -> 15%
未决: 文字乱码未改善，怀疑是负面词缺失
下一件事: 在 v06 加 text/watermark 负面词，跑 E013
```

## 子 agent 看图协议

需要看图片时，派子 agent，主上下文只接收它的结构化结论。给子 agent 的指令固定为：

```
读这些图片：<路径列表>
按五项各 0-2 分打分，不要描述画面内容，不要输出超过 8 行：
主体正确 / 手部 / 文字 / 构图 / 风格一致
最后一行给出：不合格的图号 + 缺陷类型。
```

主上下文只保留最后两行。

## 中断恢复

会话被中断时，先写一条最小记录：

```
E0NN 中断于 <步骤>，已确认 <事实>，未验证 <假设>，可复现命令 <命令>
```

不许留"下次再说"。没有写回的进度等于不存在。
